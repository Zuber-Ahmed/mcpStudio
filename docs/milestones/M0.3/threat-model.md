# Foundation threat model and required proofs

Scope: one local operator, five-screen Studio, read-only acquisition, container-backed scan/validation, immutable output and explicitly controlled exports. The host repository, browser input, inference output and remote Git/MCP metadata are all untrusted. Local-first is a topology decision, not a substitute for authorization. Review design only; no claimed sandbox/auth enforcement.

| Boundary / threat | Required controls | Verification to run before affected feature |
|---|---|---|
| Browser → loopback API / cross-site mutation | One-use launcher-bound bootstrap, host-only HttpOnly session, exact Origin, session CSRF, idle/absolute expiry, no wildcard CORS | Unknown/null/attacker origin fails; bootstrap replay/expiry fails; missing/wrong CSRF fails; logout invalidates cached session; no token in URL/log/localStorage |
| Project ID → data / ownership bypass | Server-derived actor/tenant; composite tenant keys; current authorization per lookup/download | Foreign project/plan/artifact UUID denied without disclosure; rights removal blocks subsequent generation/export |
| Git/local location → filesystem/network / traversal, SSRF | Canonical allowed roots, symlink/mount escape denial, credential references, allowlisted Git acquisition, redirect/DNS/egress policy | Malicious URL/redirect/UNC/symlink/absolute emitted path fixtures fail; local dirty snapshot digest stable for exact bytes |
| Source/plugin/model → analysis / prompt injection or code execution | Parse-only scan, bounded plugin interface, no repo scripts, source read-only, model proposals validated as data | Script canary never executes; injected instructions cannot call tools/upload; unknown findings do not gain verified status |
| Operator selection → generator / stale approval | Immutable canonical plan, source/plugin/config/policy pins, transaction+outbox, idempotency key+digest | Concurrent change/replay/revocation/body mismatch rejected; one admitted run after crash/retry |
| Worker → host/production / escape or exfiltration | Read-only snapshot, isolated output/temp, no production credentials, denied egress, CPU/memory/time/process limits | Container fixture fails write outside output, denied network, forced timeout leaves no processes/temp; host-native fallback prohibited |
| Object store/validation → approved bundle / false pass, stale bytes | Digest publication, nonempty required policy, actual check evidence, artifact-set binding, current revocation check | Changed bytes/policy or missing/skipped/not_run mandatory check blocks approved export; empty list never succeeds |
| Results → user / deceptive draft, secrets in logs | Bounded redacted preview/logs, real clipboard result, stable findings, explicit draft manifest/audit | Canary secret absent from previews/reports/bundles; binary preview denied; draft never labeled approved |
| Dependencies/images → runtime / supply-chain or mismatch | Exact manifest/lockfile and image digest, source verification, audit and protocol fixtures | Full validator/client/JCS/MCP compatibility, SDK generation consistency and container architecture proven; current candidate pins are not this proof |

Operational data requiring physical design: OS secret-store references, session hashed credentials/expiry/revocation, consent, idempotency outcomes, durable outbox and audit. Do not persist raw credentials in PostgreSQL JSON or generated content. Local cleanup procedure must expose retained paths and preserve audit/approval rules; no undocumented automatic source retention deletion promise.

Current limitations: Docker not found, dependency DNS failure, target directory not a writable root. User subsequently chose **contract files only for now**. Therefore no installation, container exercise, source acquisition or repository initialization attempted. These tests are scheduled readiness requirements rather than product-code tests hidden behind documentation counts.
